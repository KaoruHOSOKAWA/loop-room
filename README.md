# LOOP ROOM

スマホ向けの録音・ループ・スクラッチアプリです。

[アプリを開く](https://kaoruhosokawa.github.io/loop-room/)

## まず使ってみる

1. アプリを開き、下の再生ボタンを押します。最初はデモ音声が選択されています。
2. 右側の縦バーで再生速度を変えます。バー上の数字を押すと **1.00×** に戻ります。
3. 「Recorder」と書かれた盤を指で回すとスクラッチできます。
4. 自分の音声を使う場合は録音ボタンを押すか、左上のメニューから音声ファイルを読み込みます。

## 操作

下のボタンは左から **録音・再生／一時停止・CUE・巻き戻し** です。

| 操作 | 動作 |
|---|---|
| 録音 | マイクの利用を許可して録音開始。もう一度押すと録音を終了して保存します。録音中にCUEを押しても保存できます。 |
| 再生／一時停止 | 選択した音声を再生します。再生中に押すとその位置で一時停止し、再び押すと続きから再生します。 |
| 巻き戻し | 押している間、逆再生の音を鳴らしながら2倍速で巻き戻します。先頭で止まります。離すと、操作前が再生中ならその位置から再生し、一時停止中なら停止したままです。 |
| 速度バー | 0.25〜4.00倍で調整できます。中央は1倍で、対数スケールです。通常再生では音程を保ちます。 |
| 波形／シークバー | 上側に左チャンネル、下側に右チャンネルの波形を表示します。押す・ドラッグする操作で再生位置を移動できます。実線が現在位置、縦の点線がCUE位置です。盤の中央には現在位置を `00:00` 形式で表示します。 |

音声は常に全体をループ再生します。アプリ内の音量は100%固定です。音量調整は端末側で行ってください。

### CUE

CUEは、戻りたい位置を記憶するボタンです。音声を選択した直後のCUE位置は先頭です。

| 押す前の状態 | 押した瞬間 | 押している間 | 離した瞬間 |
|---|---|---|---|
| 一時停止中・CUE位置以外 | 現在位置をCUEに設定 | 停止したまま | 設定したCUE位置で停止 |
| CUE位置で停止中（Cue Standby） | CUE位置から再生開始 | 押している間だけ再生 | CUE位置へ戻って停止 |
| 通常再生中 | 既存のCUE位置へ戻って停止 | 停止したまま | CUE位置で停止 |

好きな位置を設定するには、再生を一時停止して波形で位置を調整し、CUEを押します。その後、CUEを長押しするとその位置から試聴できます。CUE位置は音声を選び直すと先頭に戻ります。

### スクラッチ

盤を時計回りに動かすと順方向、反時計回りに動かすと逆方向に音声が進みます。1周で4秒ぶん移動し、音声の端を越えるとループします。指を動かす速さに応じて音の速さと音程が変わります。

指を止めるとスクラッチ音も止まります。離すと、操作前が再生中なら続きから再生し、一時停止中なら停止したままです。録音中はスクラッチできません。

### 録音一覧

左上のハンバーガーメニューから開きます。

- 音声の行を押すと、その音声を選択できます。上部の再生ボタンでメニューを開いたまま再生・一時停止できます。
- 録音名は録音開始時の端末時刻から `yyyy-mm-dd-hhmmss` 形式で付きます。鉛筆ボタンであとから変更できます。
- ダウンロードボタンで音声をWAVファイルとして保存できます。
- ゴミ箱ボタンで録音を削除できます。デモ音声は削除できません。
- 「音声を読み込む ＋」から端末内の音声ファイルを追加できます。上限は50 MBです。

録音は最大10分です。録音中は画面を開いたままにしてください。

## 音声の保存先

録音・読み込み音声は、利用中の端末・ブラウザ内（IndexedDB）に保存します。音声をサーバーへ送信しません。スクラッチや巻き戻しの操作結果は録音に含まれません。

別の端末・ブラウザ・サイトURLには録音が自動で移りません。移したい場合はWAVでダウンロードして、移行先で読み込んでください。サイトデータの消去で録音も消えるため、残したい録音はダウンロードしてください。ブラウザ内への保存に失敗した場合も、ダウンロードで保存できます。

## マイクを使うには

マイクの利用にはHTTPSまたは同じ端末のlocalhostで開き、ブラウザのマイク権限を許可する必要があります。公開アプリはHTTPSで利用できます。PCのLAN IPをHTTPでスマホから開く場合は録音できません。

## 公開構成

このリポジトリは静的ファイルをルートに配置し、GitHub Pagesで公開しています。Node.jsサーバーは公開時には不要です。音声処理はブラウザ内で行い、スクラッチにはAudioWorkletを使っています。
